# 字体许可

本目录中的字体文件均以 **SIL Open Font License, Version 1.1** 授权，允许随网站自由使用、子集化与再分发。各字体的版权声明与许可全文在 [`licenses/`](licenses/) 目录里（由 `tools/fonts.mjs` 从字体源包原样拷贝）。

| 文件 | 字体 | 许可文本 |
| --- | --- | --- |
| `noto-serif-sc-*.woff2` | Noto Serif SC（思源宋体） | `licenses/fontsource-noto-serif-sc.txt` |
| `instrument-serif-*.woff2` | Instrument Serif | `licenses/fontsource-instrument-serif.txt` |
| `instrument-sans-var.woff2` | Instrument Sans | `licenses/fontsource-variable-instrument-sans.txt` |
| `dm-mono-*.woff2` | DM Mono | `licenses/fontsource-dm-mono.txt` |

说明：

- `noto-serif-sc-600.woff2` 与 `noto-serif-sc-900.woff2` 是按本站实际用字裁剪出的子集，由 `tools/fonts.mjs` 生成；字体源文件来自 npm 上的 `@fontsource/*` 包。
- 按 OFL 的要求：字体不单独出售；修改后的版本沿用同一许可。
